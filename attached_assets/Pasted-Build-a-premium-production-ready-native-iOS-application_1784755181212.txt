Build a premium, production-ready native iOS application with an Apple-first design philosophy. The application should feel like a product designed by Apple rather than a cross-platform app.

## Goal

Create an elegant, fast, AI-powered iOS app with exceptional UX, fluid animations, and enterprise-grade architecture.

## Design Language

Follow Apple's Human Interface Guidelines.

Use:
- SwiftUI
- iOS 18+
- SF Symbols
- Dynamic Type
- Dark & Light Mode
- Native NavigationStack
- Native Sheets
- Glassmorphism where appropriate
- Smooth spring animations
- Haptic feedback
- Blur materials
- Large navigation titles
- Native tab bar
- Native context menus
- Swipe actions
- Pull to refresh
- Live Activities (where applicable)
- Widgets
- Shortcuts integration
- Share Sheet
- Spotlight Search
- Universal Links

The application should feel comparable to:
- Apple Wallet
- Apple Health
- Things 3
- Linear
- Notion Calendar
- Arc Search
